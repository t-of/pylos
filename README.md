# pylos — ピラミッド型の陣取り

試作 ピロス（ボードゲーム）。4段のピラミッド型の盤に玉を積み、正方形を作って玉を取り戻し、頂上を取るか相手を手詰まりにしたら勝ち。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/pylos/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

4×4・3×3・2×2・頂上 1 の 4 段ピラミッドの盤に、白・黒 15 個ずつの玉を交互に置く。
手番では「手持ちの玉を置く」か「自分の、何も支えていない玉をより高い段へ動かす」かのどちらか。
同じ段に自分の色だけの 2×2 の正方形ができたら、自分の何も支えていない玉を 0〜2 個、取り戻して手持ちに戻せる。
頂上に玉を置いたら勝ち。手持ちがなく動かす手もなければ負け。

- 空きをタップ: 手持ちを置く
- 自分の動かせる玉をタップ → 行き先をタップ: 動かす（もう一度タップで取り消し）
- 正方形ができたら、光っている玉をタップで取り戻す（「おわり」でやめる）

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
